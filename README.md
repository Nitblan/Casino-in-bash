# Casino in Bash

A terminal-based casino written entirely in Bash.

This project demonstrates how far shell scripting can go beyond automation by implementing casino-style games, betting mechanics, balance management, and an interactive command-line interface using nothing but Bash.

---

## Overview

Casino in Bash is a lightweight CLI application that allows users to play casino games directly from the terminal.

The goal of the project was to create an entertaining and interactive experience while exploring game logic, randomness, user interaction, and terminal interface design in pure Bash.

---

## Features

- Multiple casino-style games
- Virtual betting system
- Balance management
- Interactive terminal menus
- Lightweight and fast
- Linux compatible
- Written entirely in Bash
- No external dependencies

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Nitblan/Casino-in-bash.git
cd Casino-in-bash
```

Give execution permissions:

```bash
chmod +x casino.sh
```

Run the program:

```bash
./casino.sh
```

---

## Gameplay

Launch the application and navigate through the available menus.

Place bets, manage your balance, and test your luck through the different games available in the casino.

Every decision affects your bankroll.
